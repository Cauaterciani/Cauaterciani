## Projeto em destaque

### MENIT — Plataforma social de comunicação em tempo real

Projeto acadêmico em equipe que reúne autenticação, perfis, conexões, conversas e presença em tempo real em uma experiência responsiva com identidade visual própria.

**O que venho construindo e aprendendo:**

- Frontend responsivo com React, TypeScript e Tailwind CSS
- API REST com Node.js, Express e arquitetura em camadas
- Autenticação com JWT armazenado em cookie HttpOnly
- Mensagens e presença em tempo real com Socket.IO
- Persistência com PostgreSQL, Prisma e migrations versionadas
- Validação de uploads, rate limiting e práticas de segurança
- Deploy em Linux com serviços, backups e banco isolado

**Stack:** React · TypeScript · Node.js · Express · Socket.IO · PostgreSQL · Prisma

> Projeto em desenvolvimento. O repositório permanece privado durante esta etapa.
